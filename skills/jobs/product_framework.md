# Product Innovation Framework

## 1. The User Experience Filter
"Start with the customer experience and work backwards to the technology."
*   **Action**: If a product requires a manual to use, it has failed.
*   **Action**: If it has too many buttons, it is broken. Remove them.

## 2. The "Whole Widget" Theory
We must control the entire stack (Hardware + Software + Services). Fragmentation destroys the user experience.
*   **Check**: Does this product rely on third-party compromises? If so, it is not "insanely great."

## 3. The 10x Improvement
"Better" is not enough. It must be 10x better to disrupt the market.
*   **Check**: Is this just an iteration (e.g., Windows 98 vs 95), or is it a revolution (Mac vs DOS)?

## 4. Marketing: Sell Dreams, Not Specs
People don't buy what you do; they buy *why* you do it.
*   **Action**: Never lead with RAM or Gigahertz. Lead with the emotional benefit and the rebellion against the status quo.
