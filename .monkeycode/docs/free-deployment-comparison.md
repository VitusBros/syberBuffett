## 🎯 最终推荐

### 方案 A：魔搭社区（首选）

**适合理由**：
1. 🚀 **国内最快**：阿里达摩院运营，国内节点直连
2. 🤗 **Gradio 原生**：API 与 HF Spaces 几乎一致，代码可无缝迁移
3. 💾 **持久存储**：ChromaDB 向量库数据可保留
4. 🆓 **免费**：无隐藏费用
5. 📚 **中文支持**：文档和社区都是中文

**部署步骤**：
1. 注册 [ModelScope](https://modelscope.cn)
2. 创建"创空间"（Gradio 类型）
3. 推送代码到创空间仓库
4. 在 Settings 添加 `SENSENOVA_API_KEY` 环境变量
5. 开启持久存储，挂载 ChromaDB 数据目录

## ⚠️ 注意事项

1. **API Key 安全**：
   - 无论哪个平台，都不要把 `.env` 提交到 Git
   - 使用平台提供的环境变量功能注入 `SENSENOVA_API_KEY`

2. **ChromaDB 持久化**：
   - ChromaDB 是本地文件数据库，必须挂载持久卷
   - 魔搭社区支持持久存储，但免费版可能定期清理不活跃数据
   - 建议定期导出 `chroma_data/` 目录备份

3. **LLM API 费用**：
   - 商汤 SenseNova API 不是免费的（虽然可能有免费额度）
   - 需要监控 Token 消耗，设置预算告警
   - 建议开发时优先使用 Mock 模式

4. **冷启动问题**：
   - 免费平台通常会在无活动后休眠
   - 魔搭社区约 2 小时无活动会释放实例
   - 用户再次访问时需要等待 30-60 秒启动
